## 📖 Sobre o projeto

Este repositório reúne os **exercícios, práticas e experimentos desenvolvidos durante um curso de férias de Programação em Inteligência Artificial**, com foco nos fundamentos de **Ciência de Dados e Aprendizado de Máquina utilizando Python**.

## 🚀 Como começar

### Pré-requisitos

Antes de executar os notebooks, recomenda-se ter instalado:

* **Python 3.9 ou superior**
* **Git**
* **Jupyter Notebook**, **JupyterLab** ou **VS Code** com a extensão Jupyter

> ⚠️ A compatibilidade entre a versão do Python e do TensorFlow pode variar. Consulte a documentação do TensorFlow caso encontre problemas durante a instalação.

### 1. Clone o repositório

```bash
git clone https://github.com/GalvaoLabs/programacao-ia-generativa.git
cd programacao-ia-generativa
```

### 2. Crie um ambiente virtual

É recomendado utilizar um ambiente virtual para manter as dependências do projeto isoladas.

```bash
python -m venv venv
```

**Windows:**

```bash
venv\Scripts\activate
```

**Linux/macOS:**

```bash
source venv/bin/activate
```

### 3. Instale as dependências

```bash
pip install -r requirements.txt
```

Ou, caso prefira instalar manualmente:

```bash
pip install pandas numpy matplotlib scikit-learn tensorflow spacy jupyter
```

### 4. Instale o modelo de português do spaCy

```bash
python -m spacy download pt_core_news_sm
```

### 5. Inicie o Jupyter Notebook

```bash
jupyter notebook
```

Depois, abra o notebook desejado e execute as células em ordem.

> 💡 **Importante:** alguns notebooks dependem de arquivos locais. O exercício de salários utiliza `Salaries.csv`, enquanto os notebooks de spaCy utilizam `texto.txt`. Para evitar problemas com caminhos relativos, recomenda-se executar os notebooks a partir de suas respectivas pastas.
